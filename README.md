# Промежуток

Неспешная головоломка о блоках, равновесии и небольших паузах для размышления. Два режима используют общие правила и физику:

- **Игра** — минималистичный экран, поле 8 × 10 и меню сбоку. Блоки длиной 1–4; движется выбранный блок и связанные с ним сверху; каждый новый ряд случайно появляется сверху или снизу после хода.
- **Прототип** — режим с параметром `?mode=prototype`: сравнение сцепления, направлений генерации, длин блоков, ручного и автоматического добавления ряда и скорости падения (0,5–20 клеток/с, по умолчанию 15) и длительности сгорания (0,6–2 с, по умолчанию 1,2 с).

## Доступ по ссылке

Постоянный адрес после публикации через GitHub Pages: <https://art3mandr33f.github.io/block-deconstruction/>. **Публикация пока не включена**, поэтому ссылка может не открываться. Для публикации нужно в настройках репозитория **Settings → Pages → Build and deployment → Source** выбрать **GitHub Actions**, затем влить эти изменения в `main`: workflow `.github/workflows/pages.yml` опубликует игру. Прототип будет доступен по тому же адресу с `?mode=prototype`.

В Arena.ai игру можно открыть прямо сейчас через **LIVE PREVIEW «Игра „Промежуток“»**; эта ссылка на предпросмотр временная и не заменяет публикацию.

## Запуск на компьютере и телефоне

Локально нужен только HTTP-сервер:

```sh
python3 -m http.server 8000
```

Откройте `http://localhost:8000`. На телефоне используйте опубликованную HTTPS-ссылку или адрес компьютера в той же сети с доступным портом; `localhost` на телефоне указывает на сам телефон. После публикации страницу можно добавить на главный экран через меню браузера («Добавить на экран Домой»). Добавлен web app manifest и иконки для установки; приложение пока требует сети и не является отдельным приложением из магазина.

Для тестов нужен Node.js 18+ и установка зависимостей разработки: `npm ci`, затем `npm test`. Сама игра запускается без установки зависимостей.

## Как играть

Выберите блок и перетащите его вместе с конструкцией. Выступы необходимо сначала освободить, но в свободном пространстве призрак может двигаться в любую сторону, в том числе вниз. Тела блоков и выступы препятствуют прохождению друг сквозь друга; при отпускании выбирается ближайшая достижимая позиция на сетке. Если узкая щель доступна, слегка смещённый призрак автоматически выравнивается для прохода. Клавиатура: выберите блок, используйте стрелки и кнопку «Разместить»; Escape или «Отмена» отменяет ход.

Полная горизонтальная линия сначала подсвечивается 0,4 секунды и затем сгорает (по умолчанию 1,2 секунды), затем неподдерживаемые конструкции одновременно падают. Если поле после очистки осталось пустым, автоматически добавляется один новый ряд, даже в ручном режиме; повторного добавления за тот же ход не происходит. За линию начисляется 100 очков с предварительным множителем для последовательных волн очистки. Если перед ходом верхний ряд уже занят и после хода остаётся занят, игра заканчивается. При автоматическом добавлении ряда игра также заканчивается, если после хода для ряда нет места. Если автоматическое добавление выключено и верхний ряд был свободен до хода, его можно попробовать освободить; при отсутствии полезных ходов игра завершается.

Цитаты в меню выключены по умолчанию. При включении за комбо показывается один из нескольких коротких вольных переводов «Дао дэ цзин» с указанием главы; выбор тем и библиотека цитат — будущая работа. Настройки и состояние пока не сохраняются после перезагрузки.

Больше деталей и технические допущения — в [agent.md](agent.md).

## Как сравнить анимацию

В прототипе настройте скорость падения и время сгорания и нажмите **«Посмотреть анимацию»**. Это сбросит текущую партию и покажет один и тот же каскад: две очистки с падением между ними, затем поле заполнится вновь. Меняйте настройки и повторяйте показ, в том числе на телефоне; приемлемость ритма определяется наблюдением, а не только заданными секундами. Падение всегда анимируется, в том числе при системной настройке уменьшения движения. При этой настройке сгорание по-прежнему заменяется короткой статичной подсветкой.

Для проверки рывков в Chrome откройте DevTools → Performance, включите Screenshots, запишите демонстрацию и посмотрите кадры и длинные паузы. CPU throttling помогает воспроизвести нагрузку, но не заменяет проверки на настоящем устройстве: [Chrome DevTools Performance](https://developer.chrome.com/docs/devtools/performance/reference). Настройки пока не сохраняются между перезагрузками.

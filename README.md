# Промежуток

Неспешная головоломка о блоках, равновесии и небольших паузах для размышления. Два режима используют общие правила и физику:

- **Игра** — минималистичный экран, поле 8 × 10 и меню сбоку. Блоки длиной 1–4; движется выбранный блок и связанные с ним сверху; каждый новый ряд случайно появляется сверху или снизу после хода.
- **Прототип** — режим с параметром `?mode=prototype`: сравнение сцепления, направлений генерации, длин блоков, ручного и автоматического добавления ряда и скорости падения (0,5–20 клеток/с, по умолчанию 15) и длительности сгорания (0,6–2 с, по умолчанию 1,2 с).

## Как запустить

### Самый простой способ: один файл

1. Откройте файл **`promezhutok.html`** из этого репозитория.
2. В GitHub нажмите на нём **Download raw file** (или «Скачать»), затем откройте скачанный файл двойным щелчком.

Ничего устанавливать не нужно: игра, стили и звук находятся внутри одного файла, работает офлайн и без сервера. Файл собран из `index.html` и `src/`; после правок исходников его нужно пересобрать командой `npm run build`. Такой же файл лежит на опубликованной странице по адресу `.../promezhutok.html`, а в меню игры есть ссылка «Скачать игру одним файлом».

Ограничения одиночного файла: его нельзя добавить на главный экран телефона как приложение (манифест и установка требуют HTTPS), а рекорды и настройки браузер может не сохранить при открытии с диска — игра при этом работает, просто без истории.

### Запуск двойным щелчком из папки

- Windows: **`start.bat`**
- macOS: **`start.command`** (в Linux: `sh start.command`)

Скрипт сам найдёт Node.js или Python, поднимет локальный сервер и откроет игру в браузере. Остановка — Ctrl+C в открывшемся окне.

### Командная строка

```sh
npm start          # сервер на http://localhost:8000 и открытие браузера
node scripts/serve.mjs --port 8010
python3 -m http.server 8000
```

Игра открывается по умолчанию, прототип — по адресу `http://localhost:8000/?mode=prototype`.

### Доступ по ссылке

Постоянный адрес после публикации через GitHub Pages: <https://art3mandr33f.github.io/block-deconstruction/>. Публикация включается один раз в настройках репозитория: **Settings → Pages → Build and deployment → Source → GitHub Actions**; затем workflow `.github/workflows/pages.yml` публикует игру при каждом изменении `main`. Прототип доступен по тому же адресу с `?mode=prototype`.

В Arena.ai игру можно открыть через **LIVE PREVIEW**; эта ссылка временная и не заменяет публикацию.

### Windows и телефон

На некоторых компьютерах Windows встроенный сервер Python отдаёт файлы `.js` с типом `text/plain`, и браузер не запускает модуль игры: поле остаётся пустым. Скрипты `start.bat`, `start.command` и `npm start` задают типы файлов сами. Если вы запускаете сервер вручную, проверьте тип: `curl.exe -I http://localhost:8000/src/main.js` — строка `Content-Type` должна быть `text/javascript`. Ошибка `Failed to load module script ... MIME type of "text/plain"` в консоли (F12) означает как раз это.

Сообщения `apple-mobile-web-app-capable is deprecated` и `404` для `/.well-known/...` или `favicon.ico` безвредны.

На телефоне используйте опубликованную HTTPS-ссылку, одиночный файл или адрес компьютера в той же сети; `localhost` на телефоне указывает на сам телефон. С HTTPS-страницы игру можно добавить на главный экран через меню браузера; офлайн-режим и приложение из магазина не реализованы.

Для сборки и тестов нужен Node.js 18+: `npm ci`, затем `npm test`. Сама игра запускается без установки зависимостей.

## Как играть

Выберите блок и перетащите его вместе с конструкцией. Выступы необходимо сначала освободить, но в свободном пространстве призрак может двигаться в любую сторону, в том числе вниз. Тела блоков и выступы препятствуют прохождению друг сквозь друга; при отпускании выбирается ближайшая достижимая позиция на сетке. Если узкая щель доступна, слегка смещённый призрак автоматически выравнивается для прохода. Клавиатура: выберите блок, используйте стрелки и кнопку «Разместить»; Escape или «Отмена» отменяет ход.

Полная горизонтальная линия сначала подсвечивается 0,4 секунды и затем сгорает (по умолчанию 1,2 секунды), затем неподдерживаемые конструкции одновременно падают. Если поле после очистки осталось пустым, автоматически добавляется один новый ряд, даже в ручном режиме; повторного добавления за тот же ход не происходит. За линию начисляется 100 очков с предварительным множителем для последовательных волн очистки. Линии, сгоревшие до и после появления нового ряда, считаются вместе: «одна линия до и одна после» — это две линии за ход и повод для цитаты.

Если перед ходом верхний ряд уже занят и после хода остаётся занят, игра заканчивается. При автоматическом добавлении ряда игра также заканчивается, если после хода для ряда нет места. Если автоматическое добавление выключено и верхний ряд был свободен до хода, его можно попробовать освободить; при отсутствии полезных ходов игра завершается.

## Цитаты и озвучка

В меню две настройки: **«Показывать цитаты»** и **«Озвучивать цитаты»** (обе выключены по умолчанию, выбор запоминается в браузере). Цитата появляется, когда за ход сгорает больше одной линии или волн очистки было несколько. Это короткие вольные пересказы «Дао дэ цзин» с указанием главы.

Цитаты выбираются случайно, но не повторяются подряд: только что показанная получает нулевую вероятность, предыдущая — половину обычной, и так далее; вес постепенно возвращается (см. раздел «Адаптивное распределение» в [agent.md](agent.md)). История показанного хранится в браузере, поэтому «свежие» цитаты остаются редкими и между сессиями.

Озвучка использует системный синтезатор речи браузера (Web Speech API), а не готовые аудиодорожки: так пользователь сможет добавить свой цитатник без записи звука, а размер игры не растёт. Голос, темп и наличие русского голоса зависят от устройства; если синтезатора нет или русского голоса нет, цитата просто показывается текстом, а настройка озвучки недоступна. Слова цитаты открываются по мере произнесения; при системной настройке уменьшения движения текст появляется сразу целиком. Кнопка **«▶ Озвучить»** под цитатой читает её заново, **«■ Остановить»** прерывает чтение.

## Рекорды

В меню есть блок **«Рекорды»**: лучший счёт, наибольшее число линий и список последних лучших партий. Результат записывается, когда партия завершена. Рекорды хранятся в браузере (localStorage) и не передаются никуда; если хранилище недоступно, они действуют до перезагрузки. Кнопка **«Очистить рекорды»** спрашивает подтверждение вторым нажатием. В прототипе рекорды не пишутся: правила там настраиваются, и сравнивать такие партии нельзя.

## Как сравнить анимацию

В прототипе настройте скорость падения и время сгорания и нажмите **«Посмотреть анимацию»**. Это сбросит текущую партию и покажет один и тот же каскад: две очистки с падением между ними, затем поле заполнится вновь. Меняйте настройки и повторяйте показ, в том числе на телефоне; приемлемость ритма определяется наблюдением, а не только заданными секундами. Падение всегда анимируется, в том числе при системной настройке уменьшения движения. При этой настройке сгорание по-прежнему заменяется короткой статичной подсветкой.

Для проверки рывков в Chrome откройте DevTools → Performance, включите Screenshots, запишите демонстрацию и посмотрите кадры и длинные паузы. CPU throttling помогает воспроизвести нагрузку, но не заменяет проверки на настоящем устройстве: [Chrome DevTools Performance](https://developer.chrome.com/docs/devtools/performance/reference).

# Заметки для разработки

## Замысел

Сделать неспешную головоломку, вдохновлённую Block Slide, но с исследуемой физикой сцепления и падения. Философский слой — необязательное знакомство с мудростью книг через цитаты во время игры. Механика должна оставаться понятной и без него; цитаты предполагаются выключенными по умолчанию.

## Текущее состояние

Статический веб-прототип без зависимостей: `index.html`, `src/styles.css`, `src/main.js`, `src/board.js`. Модель создаёт независимые ряды из пустых ячеек (`null`), интерфейс отображает их как сетку. Поле имеет 8 столбцов и 10 рядов; индексы в модели идут сверху вниз и слева направо, с нуля. В интерфейсе координаты для доступности нумеруются с единицы. Проверка: `npm test` (Node.js). Запуск через `python3 -m http.server 8000`.

**Не реализовано:** блоки, ходы, сцепление, гравитация, удаление линий, генерация, цитаты и подсказки. Не представлять эти функции как работающие.

## Направление правил

- Блоки 1×1–1×4; горизонтальная линия из 8 занятых клеток исчезает.
- После очистки или потери опоры что-то падает: единица падения, связь и опора пока не определены.
- Сцепление по принципу лего, создание следующей линии по кнопке и цветные анимированные подсказки — гипотезы. Не фиксировать спорные детали без согласования.
- При проектировании физики отдельно определить состав группы, проверку допустимости движения, обработку пересекающих очищенную строку блоков, порядок очистки и падения и возможные повторные очистки. Покрыть утверждённые правила тестами до добавления анимаций.
- Цитаты из «Бхагавад-гиты» или «Дао Дэ Цзин» — возможное дополнение, с выбором оформления и выключением; по умолчанию выключены. Проверять права на используемые тексты и переводы, указывать источники; не приписывать выдуманные цитаты книгам.

## Принципы работы

Сначала задавать вопросы там, где правила неоднозначны. Отделять согласованные требования от гипотез и обновлять README по мере принятия решений. Сохранять доступность, адаптивность и спокойный визуальный язык. Избегать лишних зависимостей и фиктивных работающих элементов управления.

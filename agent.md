# Заметки для разработки

## Замысел

Неспешная головоломка, вдохновлённая Block Slide, с экспериментальной физикой сцепления и необязательными цитатами. Цитаты выключены по умолчанию. Сейчас используются короткие вольные переводы древнего «Дао дэ цзин» с указанием главы; при добавлении текстов проверять права на конкретные переводы и не приписывать выдуманные цитаты авторам.

## Версии и запуск

`index.html` — минималистичная игра; `?mode=prototype` — экспериментальный интерфейс. Общие модель и интерфейс находятся в `src/`, отдельной копии физики нет. Игровой режим фиксирует длины 1–4, режим сцепления «выбранный и выше», случайное направление и автоматический ряд после хода. Прототип позволяет переключать правила и скорость падения 5–10 клеток/с. В игре есть меню рестарта и цитат; настройки не сохраняются.

Запуск: `python3 -m http.server 8000`, тесты: `npm test`. На телефоне используется адаптивная веб-версия и сенсорное перетаскивание. `manifest.webmanifest` и иконки позволяют добавить страницу на главный экран после публикации по HTTPS; офлайн-режим и нативное приложение не реализованы. `.github/workflows/pages.yml` готовит статический сайт для GitHub Pages, но сам по себе не включает Pages в настройках репозитория. Ожидаемый URL и шаги публикации — в README.

## Правила и физика

Поле 8 столбцов × 10 рядов, координаты модели с нуля, сверху вниз. Блок горизонтальный и занимает один ряд. Связь возникает при вертикальном контакте с перекрытием хотя бы в одну колонку. Режимы: все связанные блоки либо выбранный и связанные цепочкой вверх.

`src/board.js` отвечает за генерацию, модель, синхронное поклеточное падение и очистку. При перетаскивании `src/drag.js` проверяет непрерывные столкновения тел и отдельных выступов на обеих конструкциях; выступы, вставленные в блок при исходном положении, должны сначала разъединиться вертикально. Нет общего запрета бокового движения по исходной высоте. При отпускании призрак может вертикально войти в паз, затем положение привязывается к ближайшей достижимой целой клетке. Геометрия выступов берётся из CSS и используется как при рисовании, так и при проверке столкновений; круглое оформление тоже сохраняет видимые верхние выступы. Тестировать сцепление, свободное движение, узкий проход и отсутствие туннелирования.

Очистка всех заполненных строк волны одновременна; свободные конструкции падают синхронными шагами. `resolveBoard` отдаёт кадры, `src/motion.js` объединяет последовательные падения в непрерывную анимацию; очистка отдельно показывается 320 мс. Настройка скорости меняет продолжительность визуальной анимации, а не логику. Сброс отменяет прежние кадры и отложенную автогенерацию. Учитывать `prefers-reduced-motion`.

Если верхний ряд был занят перед совершённым ходом и остался занят после его разрешения, игра заканчивается. При автоматической генерации игра также заканчивается, когда после хода невозможно добавить ряд. В ручном режиме при первоначально незанятом верхнем ряде можно продолжить, пока остаётся полезный ход; проверка ходов в `drag.js` использует ту же геометрию выступов. Счёт и баланс предварительные.

Согласованные требования и гипотезы держать отдельно, обновлять README после решений; тестировать физику независимо от интерфейса, сохранять доступность и мобильное управление.
